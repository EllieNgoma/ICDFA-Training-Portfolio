## Security Risk of Fail-Open Mode

Fail-Open mode allows traffic to pass without inspection when HTTPS Inspection fails, potentially allowing malicious encrypted traffic to bypass inspection controls.

# Theory Questions

## What does Outbound HTTPS Inspection do?

**Answer:** Inspects encrypted traffic from internal users to external websites.

## What does a gateway need for Inbound HTTPS Inspection?

**Answer:** The web server certificate and private key.

## Why must the outbound CA certificate be installed on client computers?

The certificate ensures that browsers trust certificates generated by the gateway during HTTPS Inspection.

## Why should some trusted sites be bypassed?

To avoid privacy, compatibility, and certificate validation issues on sensitive websites such as banking services.
